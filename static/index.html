    キーバインド
    • ドラッグ: 制御点を動かす
    • ← →: 前/次フレーム、Enter: 確認済みにして次へ
    • h l / Shift+h Shift+l: 全体を左右に 1px / 5px
    • j k: 傾き（下端固定で上端を左右）
    • 1 2 3: class を straight / left / right
    • d: add / delete モードの切替（既定 add、右上に表示。行 0〜24 は編集不可）
    • 行をクリック: add では点を置く（既にあれば位置更新）／ delete では点を消す。操作した行が始点になる
    • Shift+クリック: 始点〜その行を add では直線補間、delete ではまとめて削除（両端含む）
    • 始点（範囲操作の輪／×印）は次でクリア（解除）される: フレーム移動、Tab、d（モード切替）、 n / x（エントリ追加・削除）、undo / redo、Shift+クリックの実行後
    • n / x / Tab: エントリ追加 / 削除 / 切替
    • p: 前後 ±N へ伝播、, .: 伝播幅 N を増減
    • [ ]: 制御点数 K を増減
    • R: 制御点から曲線を再生成
    • u / Ctrl+u: undo / redo
